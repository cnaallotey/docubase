Is the open source version limited?

No. The hosted plans run the same code you can run yourself. Paying buys you not having to run a server, not features.

Who pays for Ask AI?

You do, directly. The assistant uses your own Anthropic or OpenAI compatible key, stored encrypted. We never resell tokens or count credits.

Can coding agents read my docs?

Yes. Every page is published as Markdown with llms.txt beside it, and an MCP server lets agents search and read your docs, locally or hosted.

What happens if I stop paying?

Your sites stay online at their docubase address. Custom domains stop answering and saved assistant keys are ignored until you subscribe again. Nothing is deleted.

Can I leave?

Your docs are Markdown in your own repository. Run npx docubase build and host the output anywhere.
