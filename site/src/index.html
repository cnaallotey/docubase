    How it works

    Live docs in three simple steps

    From a folder of notes to a site people can search, in the time it takes to read this page.

    01

    Write

    Plain Markdown in a folder, with callouts, tabs and code blocks when you need them.

    $ npx docubase build docs

    reading 42 pages

    checking links and anchors

    building the search index

    writing llms.txt and MCP snapshot

    ✓ built in 1.4 s → dist/

    $ git push

    ✓ live at docs.example.com

    02

    Build

    Folders become the sidebar. Every page gets search, contents, dark mode and a Markdown copy.

    03

    Ship

    Static output for any host, a Docker image, or hosting that rebuilds on every push.

    Built for each stage

    From the first page
    to the thousandth reader
